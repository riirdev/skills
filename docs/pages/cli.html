Pure std Rust · #![forbid(unsafe_code)]

Zero-Dependency riir-skills CLI.

Compiles offline in under a second with zero external crates. Safely manages cross-tool skill installs via dry-run planning, SHA-256 manifests, and conflict protection.

Subcommands

All mutating commands default to dry-run and require --apply to write to disk.
