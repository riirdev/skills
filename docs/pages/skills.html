Progressive Disclosure Architecture

Seven Skills, Zero Overlap.

Each skill keeps its entrypoint compact for fast agent discovery and links deep playbooks on demand inside references/.

1. riir

End-to-end orchestrator for Rewrite It In Rust initiatives. Guides route selection (Routes A–D), Phase 0 blueprinting (pinned read-only baseline, PORTING.md, LIFETIMES.tsv, Risk Spikes, 3-File Pilot), colocated convergence vs. clean single-track cutover, DB persistence identity, and Phase-2 hardening.

References: strategy-matrix.md · blueprinting-templates.md · multi-agent-orchestration.md

2. rust-parity-testing

Proves behavioral, ABI, error-path, encoding, persistence, and artifact equivalence via Record → Replay → Diff → Shadow → Gate, 12-dimension parity checks, the L0–L5 ladder, guard mutation testing, paired direct-probe attribution, and host-app release rehearsal.

References: twelve-dimensions.md · differential-harness.md

3. rust-ffi-bridge

Designs narrow C/C++, N-API, PyO3, WASM, and mobile UniFFI seams; verifies compiled JVM bytecode, final-archive symbols, R8 keep rules, and stripped iOS bitcode; seals panics across extern "C"; and drives temporary bridge retirement.

References: abi-and-layout-gates.md · strangler-bridge-lifecycle.md

4. rust-unsafe-hardening

Turns mechanical ports into layered safe Rust via stages U1–U8: pure-logic extraction, replacing setjmp/longjmp, generational handles against ABA, zero static mut, 100% // SAFETY: invariants, and CI ratchets.

References: staged-hardening-playbook.md · safety-comment-standard.md

5. rust-architecture

Establishes acyclic workspace crate DAGs (core → sys → runtime → thin shells), CLI-as-kernel discipline, typed domain errors, bounded shutdown, clean-slate contracts, and Git-only clean-checkout rebuilds.

References: workspace-blueprints.md · clean-rust-checklist.md

6. rust-performance

Separates latency, throughput, and memory axes; enforces fair cold/warm regression baselines; and targets top-10 Rust port pitfalls including clone storms, redundant UTF-8 checks, lock contention, and chatty IPC/FFI boundaries.

References: benchmarking-protocol.md · hot-path-patterns.md

7. rust-dual-lang

Maintains strict 1-for-1 correspondence when Rust evolves long-term alongside a companion language: paired implementation order, shared JSON/JSONL contract tests, decoupled coverage gates, and anti-gaming checks.

References: paired-parity-workflow.md
